# TRD-8004751b: Report dangling retired-skill links in repository projections

## Context

On 2026-10-04 the ki-agentic-harness .claude/skills and .agents/skills projections each held seven dangling symlinks to retired skill names (ki-change-management, ki-change-management-housekeeping, ki-change-management-roadmap, ki-feature-definitions, ki-harness, ki-housekeeping-granola, ki-roadmap); ki-arcadia-principal .claude/skills held five (ki-change-management, ki-kb, ki-kb-activities, ki-kb-live-artifacts, ki-kb-streams). 'ki repo diag' reported HEALTHY=1 and 'ki repo repair --dry-run' reported 'would result: healthy' while they were present. Dangling entries in a runtime skill directory can surface as unresolvable skills to agents.

## Submission

Consider having 'ki repo diag' report dangling symlinks inside KI-managed projection directories (at least those whose names match the ki- prefix or a known retired capability) and 'ki repo repair' remove them, so stale projections are visible and reconcilable.

## Constraints

Finding only; receiver decides whether and how to act. The harness links were already removed locally; Arcadia's remain for its owner.
