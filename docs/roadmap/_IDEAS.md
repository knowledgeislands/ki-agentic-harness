# Ideas

Ideas this repository may take up later. None is a work record: an idea here has no identifier, horizon or status, and it returns to the roadmap only when Kris brings it back. Each bullet says in plain language what the idea is for and links to its full text in `docs/ideas/`, kept as it was when it left the roadmap under the roadmap sweep of 27 October 2026.

- **PreToolUse quietening hook** - A Claude Code hook that would quieten noisy tool output automatically; the quiet-tools rule in briefs covers this for now. [Full text](../ideas/KI-HARNESS-GOV-204-pretooluse-quietening-hook.md) (was `KI-HARNESS-GOV-204`).
- **Home the work spec** - Give the portable work-package specification a home in the ki-work-package skill, so people outside Knowledge Islands can read or write one; waits on the portable-specifications Project. [Full text](../ideas/KI-HARNESS-GOV-228-home-work-spec.md) (was `KI-HARNESS-GOV-228`).
- **Home the acquire spec** - Give the portable acquire-package specification a home in the ki-acquire skill; waits on the portable-specifications Project. [Full text](../ideas/KI-HARNESS-GOV-229-home-acquire-spec.md) (was `KI-HARNESS-GOV-229`).
- **Knowledge package skill** - A new skill for a portable knowledge package, a skill whose focus is condensed knowledge rather than an action; waits on the portable-specifications Project. [Full text](../ideas/KI-HARNESS-GOV-230-knowledge-package-skill.md) (was `KI-HARNESS-GOV-230`).
- **Review ThoughtWorks Radar** - Review each new ThoughtWorks Technology Radar volume as an input to the KI tool radar; the weekly model-radar review can carry this as a per-volume check. [Full text](../ideas/KI-HARNESS-REV-012-thoughtworks-radar-input.md) (was `KI-HARNESS-REV-012`).
- **Repository storage declarations** - Let a repository declare in .ki.toml what its tool or app stores in the XDG config, data, cache and state folders and why; feeds only the Observatory's Machine instrument, itself an idea. [Full text](../ideas/KI-HARNESS-GOV-227-repository-storage-declarations.md) (was `KI-HARNESS-GOV-227`).

[Full text](../ideas/KI-HARNESS-OPS-009-complete-ai-session-acquisition.md) (was `KI-HARNESS-OPS-009`).
