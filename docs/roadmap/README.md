# Roadmap areas

This index defines the fixed issuing areas declared in `.ki.toml`. An area is only an identifier namespace: grouping lives in each record's `kind`, `purpose`, `project`, `initiative` and `component`. The records themselves, and the [issue ledger](_ISSUES.md), are the queue.

## Areas

- `FND` - foundation tooling: shared checker, rubric and adapter machinery that the skills build on.
- `GOV` - governance consistency: the content of the skills and standards, and how they agree with one another.
- `OPS` - operations: running the harness and the estate it serves, such as observability, session acquisition and state cleanup.
- `REV` - regular reviews: periodic, independent assessments of the harness as a whole.
- `RTP` - runtime portability: making the skills work across Claude Code, Claude Desktop, Codex and sandboxed runs.
