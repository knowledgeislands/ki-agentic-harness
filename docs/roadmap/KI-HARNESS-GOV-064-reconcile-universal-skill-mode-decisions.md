# Reconcile universal skill mode decisions

## Goal

Remove contradictory current authority over the number and meaning of universal skill modes.

## Context

`ADR-KI-HARNESS-007` states that governance skills expose exactly four universal modes. `ADR-KI-HARNESS-SKILLS-001` states that governance skills expose a fifth universal HELP mode. Both records are current and therefore present overlapping, inconsistent authority.

## Boundary

Preserve distinct decisions if one owns executable operations and the other owns interaction vocabulary, but remove the contradictory universal-mode count. Do not silently supersede either record or broaden HELP semantics without an explicit decision review.

## Discussion

Readiness should compare enacted skill behaviour and current standard text, name the authoritative boundary of each record, and decide whether in-place reconciliation or explicit supersession is clearest.
