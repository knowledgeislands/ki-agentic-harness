It is the only package repository so far, so every rule here is drawn from one case (n=1).
- Kris's words of 1 November 2026, sent to the Stoa work by HNR's sites State of play as STOA-NO-CONSUMERS and its addendum, set [Consumers](standards-package-repositories.md#consumers): "There should be no reference out of Knowledge Islands to other territories", and consumers are found by "patterns that it knows about that would identify that it's been used".
- The Cairn summit's change 25, the guilds change, in Kris's Cairn store, records Kris's decisions of 14 November 2026: STORYBOOK-APP, that every package repository has `apps/storybook/`, built to static files, in place of `apps/workbench/`, chosen over Ladle, Histoire, React Cosmos and Pattern Lab, with Fluent UI's `apps/public-docsite-v9` as the model; ELEMENTS-MANIFEST, that each web component package publishes `custom-elements.json` from the Custom Elements Manifest analyser, as Spectrum Web Components and Shoelace do; ELEMENTS-MULTI, that a package repository may hold one package per layer, each copied and locked on its own; and COMPONENT-LIBRARY, the words component library and web component library.
