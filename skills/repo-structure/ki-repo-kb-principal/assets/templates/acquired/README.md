# Acquired packets

This is the territory principal's inbound area for whole packets delivered by the acquire port. The port alone delivers packets here; this scaffold grants no permission to dispatch, commit or push across repositories.

Each delivery has its own folder containing one whole capture package or a roll-up of related packages. Keep the packages' original folder names and bytes. Delivery adds no manifest, dispatch ID or ledger, and delivery is acceptance.

The receiver triages their local packets under their own governance: file the packet, turn it into work, or park it here for later. Canonical adoption and work selection remain receiver-owned decisions. Write nothing back into the port. Handle a misdelivery case by case; there is no return route or return marker.

The `ki-repo-kb-principal` overlay owns this exact README and requires it while the overlay is declared. Its CONFORM restores the scaffold without changing delivery packets. The `ki-repo-kb` skill owns receiver triage guidance.
