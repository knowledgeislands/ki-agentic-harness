# Machine

A machine is the computer, physical or virtual, that [environments][industry.environment] run on.

Networking calls a machine a host, and OpenAI and Google write "host" or "host machine" for one; here it is always machine, so host never stands alone (HOST-SENSES). A virtual machine is a machine; a container or sandbox inside one is an environment, not a machine.

## Our conventions

A rig, the system's word for one of Kris's workstations, such as terra or sol, maps onto a machine; its card comes with the system's own terms.
