# Agent

An agent is what you deal with when work gets done: it reads, acts and reports in the world where a model alone cannot.

An agent is a [model][industry.model] working through an [agent harness][industry.agent-harness]. The model decides each step and the harness carries it out. Vendors name an agent after its harness, so a product name can mean the agent or its harness, by context.

## Our conventions

The definitions under the KI harness's `subagents/` folder describe roles an agent takes when it is run as a subagent, not agents of their own; the [subagent][industry.subagent] card places them.
