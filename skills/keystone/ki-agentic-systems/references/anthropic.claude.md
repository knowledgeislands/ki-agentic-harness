# Claude (Anthropic)

Anthropic uses Claude as a name in more than one sense, so each sense is its own link:

- **The model family:** Claude Opus, Sonnet, Haiku and Fable are [models][industry.model] ([Models overview][a1]).
- **Claude Agent:** the name Anthropic prefers for partners' [agents][industry.agent] built on the Claude Agent SDK ([Agent SDK overview][a4]).
- **The Claude app and Claude Desktop:** [agent hosts][industry.agent-host], whose windows are their clients.

Claude also names a way to start work in Slack. VS Code calls Claude one of its [agent harnesses][microsoft.agent-harness].
