# Conversation (Anthropic)

On claude.ai, Anthropic calls a [session][industry.session] a conversation ([Claude Code glossary][a3]), where Claude Code says [session][anthropic.session]. Conversation is also the plain word for any exchange, so the match is close rather than exact.
