# Model (Microsoft)

Microsoft and GitHub say model in the industry's sense of a [model][industry.model], chosen in Copilot's model picker ([Copilot supported models][m2]). Copilot itself is not a model: it chooses among other vendors' models and Microsoft's own.

## Examples

- MAI Thinking and MAI Code, Microsoft's own ([MAI models][m1]).
- The other vendors' models GitHub Copilot mostly serves ([Copilot supported models][m2]).
