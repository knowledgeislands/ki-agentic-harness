# Harness (OpenAI)

OpenAI's "harness" is the industry's [agent harness][industry.agent-harness]: its engineering post of 4 February 2026 names the "Codex harness" ([Unlocking the Codex harness][o3]), though its documentation says "the Codex agent" for the product built on it ([App Server][o4]).

## Examples

- The Codex harness, served by the Codex App Server ([App Server][o4]).
- The Codex SDK.
- The OpenAI Agents SDK, a run loop with handoffs ([Agents SDK sessions][o5]).
