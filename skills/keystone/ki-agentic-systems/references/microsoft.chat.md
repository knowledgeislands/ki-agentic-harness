# Chat (Microsoft)

In VS Code's [agent session][microsoft.agent-session], and in the Agent Host Protocol, a chat is one part inside the [session][industry.session] ([Build with agents][m3], [What is AHP][m8]), so it is related to the session rather than another word for it. In the ChatGPT desktop app, by contrast, a [chat][openai.chat] is the whole session.
