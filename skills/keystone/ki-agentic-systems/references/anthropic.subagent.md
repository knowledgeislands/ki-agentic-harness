# Subagent (Anthropic)

Anthropic says subagent in the industry's sense of a [subagent][industry.subagent]: "A subagent stays inside the session that spawned it" and "returns a summary to the main conversation" ([Claude Code glossary][a3]).

- Claude Code's subagents, such as Explore, Plan and general-purpose ([Subagents][a5]).
- Subagents run in the foreground or the background, or as forks ([Subagents][a5]).
