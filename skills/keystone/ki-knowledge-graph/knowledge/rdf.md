# RDF

[RDF][rdf-concepts], the W3C Resource Description Framework, describes things as statements of subject, predicate and object, called triples. Resources and relationships are named by [IRIs][iri], so statements from different sources can be combined into one graph.

How Knowledge Islands uses RDF, as the intended backbone of its [knowledge graph][graph], is set out in [RDF Foundations][foundations].
