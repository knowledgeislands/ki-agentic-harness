# Batches

`+/_BATCHES/` holds temporary batch inputs to further repository work. `ki-batch` owns the record shape, authority, run ledger, and [retention rule](../../skills/change-management/ki-batch/references/standards-batch.md#batch-retention).

Keep active or uncertain records. Regular `ki-next` and `ki-recap` maintenance removes verified inactive records only after more than seven days without activity and after useful outcomes are retained in their canonical work records.
